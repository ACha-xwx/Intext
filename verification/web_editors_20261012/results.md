# WebView2 编辑迁移验收

日期：2026-10-12

## 结果

隐藏 Tk 根窗口时，需求修改曾创建 `transient(root)` 编辑窗口并调用 `grab_set()` / `wait_window()`。窗口不可见，桥接调用无法返回，使主界面和设置均失去响应。现在需求/候选、完整方案及关键工作、最终附注和需求冲突均使用主 WebView2 内的非阻塞编辑器；打开、保存、取消即时返回。

方案字段、步骤顺序、关联需求/关键工作、依赖与复核状态继续通过 SessionState 的既有保存和失效逻辑。编辑器 ID、会话 owner、basis 和版本戳保护跨会话迟到保存。校验错误留在面板中，草稿可继续编辑；错误和生命周期写入 Debug，不写正文或 API Key。正常 Web 路径保持 Tk root 隐藏，显式 Tk 回退与操作系统文件/目录选择保留。
