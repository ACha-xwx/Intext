## 故障与产品目标

PromptSmith 将用户需求、方案与所选 Skill 组织成交给另一 AI 的提示词。Skill 格式、工具前提或模型建议尚待核对，应带入最终提示；内容完整性不应成为 M4 的交付关卡。

用户粘贴的 M1 错误发生在 HTTP 成功之后。首个返回同时判断 `sufficient` 与继续追问；随后两次返回引用历史缺口 `gap-ui-priority`，当前 gaps 已为空，但待处理回答 a7 仍引用它，且“默认亮色主题”的来源有效。此前校验把状态/历史差异当成错误。

用户提供的 M4 诊断包有完整 53 项贡献。仅 contributions[8] / [33] 多出的 `outputs=[]` 触发 additionalProperties=false，已有 expected_outputs 与使用建议并未缺失。

## 当前处理

| 范围 | 可恢复处理 | 保留的边界 |
|---|---|---|
| M1 对话整理 | 围栏/额外字段/列表差异、回答判断协调；真实待处理回答可关闭历史缺口；无法可靠落地时沿现有访谈继续引导 | 用户来源、回答关联、任务/请求/版本、确认 |
| M2 方案 | 缺少描述标为未知，整理编号/覆盖/失效引用/循环，保留有效依赖，新增未知随提示交付 | 方案依据与用户确认；无法识别成方案仍提供补充/重试 |
| M3 候选参考 | 缺评估、错引用和不一致覆盖整理为条件参考，原内容留作附注 | 候选来源来自实际批次；错误请求不得采用 |
| M4 Skill 整合 | 额外字段、不完整贡献、对象/列表差异、未知编号、非 JSON 建议或模型内容错误降为附注；从已选来源补齐读取/使用/询问说明 | 实际选用集合、请求身份、取消、版本；空响应或重复 JSON 键仍是真正错误 |
| M5 示例 | 维度差异、长度、相同选项、约束冲突及未确认条件显示提醒，完整文字保留 | 反馈只是待确认候选；没有可读选项时可直接回答/跳过 |
| 最终提示 | 补齐所有已选 Skill 的名称/来源/任务用途，未知前提和可选建议带出；可直接生成参考提示 | 当前来源快照、版本、渲染一致性、用户确认 |

界面在所有阶段提供下一步文字。Skill 区新增“用已选 Skill 直接生成提示词”，不调用模型。失败后恢复忙碌状态，保留选择和旧结果；提示关联会话、方案与 Skill 修订，普通刷新不覆盖它，依据变化后不显示旧提示。

兼容修复记录 WARNING；原返回与有效返回分别保存，check.normalization 留存恢复动作。准备请求、网络调用、解析和结果落地失败记录完整异常链。Debug 的颜色及手动保存策略保持，关闭/清屏不删除本次待保存记录。
