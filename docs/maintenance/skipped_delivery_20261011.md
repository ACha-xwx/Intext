# 跳过事项与统一结果操作

## 问题与行为

“跳过”此前只改变了问题的回答状态，未知事项仍以 `user_skipped` 留在活动缺口中。阻断判断、M2 输入、源快照并集以及最终正文继续使用它，导致提示词包含用户已经跳过的问题和“先做草稿”的整段说明。

本次把单题跳过定义为明确排除：不重新询问、不当成方向阻断、不放入方案缺口或最终提示。原问题与选择保留在会话历史，用户仍可主动补答。`unsure` 保留真实未知；“保留剩余未知”和“先做草稿”的整批操作记录为 `unsure`，不与单题排除混用。

## 实现边界

- `clarification.py` 按最新回答和主动重开状态投影排除项，使用来源编号、原始描述识别历史副本，不猜测未提供的答案。
- `SessionState.active_gaps()` 用于前期问题、阻断、需求预览、方案输入与草稿授权。原 `gaps` 和回答历史保留，版本/来源/确认保护继续生效。
- M1 提示明确区分跳过和不确定。本地解析丢弃同一题及同范围新编号的重复追问，保留其他问题，减少无意义的自动修正请求。
- M2 承接明确跳过的访谈选择，输入缺口不再包含该题；解析后若模型在未知集合复述原题，由程序排除。M3/M4 环境和 M4 方案快照使用相同交付投影。
- 最终正文和导出承接过滤后的基线。旧会话打开时清理结构化未知及相关草稿授权说明，再重新渲染缓存、更新正文哈希；原结果存入历史，撤销原最终确认，仍可直接复制/导出。
- 已形成当前方案后不再自动派生题卡；用户主动补答、新增要求仍能进入前期整理并使旧成果失效。

旧格式基线同样排除跳过项。方案编辑/确认验证保持原始内容与原始来源快照一致，交付使用有效投影；不把历史来源删除后再错误地判定原方案有悬空引用。

“语气和附注”此前调用 `show_workspace(3)` 回到旧结果页，现使用统一工作区的锚定动画面板。语气更新及附注编辑仍调用原业务方法；附注修改最终正文、递增版本并撤销旧最终确认，窗口仍留在对话工作区。新增方法使用独立名称，避免被 `GuidedFlowMixin.toggle_result_options()` 的旧入口覆盖。
