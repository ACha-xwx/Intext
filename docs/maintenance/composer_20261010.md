# 输入框与模型选择组件复刻

最新字体来源为 Tk 平台默认，已取消自定义和磁盘字库；组件复刻、浅深主题与菜单交互保留，见 [默认字体](native_fonts_20261010.md)。

## 目标与范围

依据用户提供的「AI 提示词输入框@senommu」与「模型选择@AdiKodez 联动AI 回复 @jahed」TSX，复刻到当前 Tk 统一对话。以示例形态和交互为基础，仅按要求替换模型菜单、中文化、更新模型及参数、删除语音/录音/加号菜单并保留常驻发送箭头。业务仍由 SessionState 与现有工作流管理。

## 组件规格

| 区域 | 复刻结构与行为 |
| --- | --- |
| 输入面板 | 白色面板、约 28px 圆角、两像素边框、轻微底部阴影，聚焦强调边框 |
| 文本 | 无内边框，多行输入随内容增长，超过六行内部滚动，中文轮换占位文案不属于实际内容 |
| 工具栏 | 横向分隔线，下方左侧胶囊模型按钮、右侧圆形上箭头；没有语音、录音、加号或展开工具 |
| 发送状态 | 始终显示；空白与后台忙态禁用；忙时保留草稿。Enter 发送、Shift+Enter 换行，粘贴/撤销/程序填入同步更新 |
| 模型按钮 | 提供商原图标、当前模型全名的可用宽度截断、强度阶梯与下拉箭头；完整名称可在菜单读取 |
| 弹层 | 左侧提供商图标栏，右侧搜索/结果数/可滚动模型列表；各模型显示中文描述、选中勾及能力标签 |
| 搜索 | 搜索所有分类的名称、ID、提供商与描述；可清空，空结果给中文提示；切换分类清空搜索 |
| 思考强度 | 底部四档 Low / Medium / High / Max，默认 High，选中底色；方向键切换，Home/End 跳到首尾。支持参数折算时说明实际档位 |
| 应用选择 | 选择模型后保持弹层打开，可继续调强度；已确认的同一接口内直接应用并加密保存。接口未确认/变更或其它参数草稿需从右上角设置核对。菜单没有设置/确认按钮，测试连接仍不确认 |
| 关闭与恢复 | Escape、点击外部或失去焦点关闭；后台启动关闭弹层并禁用模型修改。重开使用当前配置，自定义及获取的模型仍可见 |

保留 Tab、模型列表上下/Home/End、提供商上下键、搜索 Enter/Down、按钮 Enter/Space。原生 Tk Canvas 与文本不会具备浏览器 ARIA/Framer Motion 运行环境；采用原生焦点和交互状态还原组件。按用户追加四张参考图提供浅深两套配色，在设置→界面选择并保存；新增控件不创建新业务状态。

菜单提供商轨和选中行均使用圆角，模型描述单行截断、悬浮显示完整名称/说明，能力标签用紫色推理与青色图像理解图标胶囊。DeepSeek 只有推理。滚动条随主题变化，内容不溢出时隐藏；可拖动浏览大量接口模型。思考强度显示阶梯图标；展开箭头随菜单状态变化。主题按明确语义更新文字、光标和占位颜色，避免浅色共用颜色值在深色回退时混淆。

## 2026-10-10 官方目录核对

| 分类 | 目录 API ID | 四档思考请求 |
| --- | --- | --- |
| OpenAI | gpt-6-astra、gpt-6.1-sol | low / medium / high / max；Responses reasoning.effort；Chat reasoning_effort 与 max_completion_tokens |
| Anthropic | claude-opus-5-5、claude-fable-5-1、claude-sonnet-5-5、claude-haiku-5-5 | low / medium / high / max；Messages thinking.type=adaptive 与 output_config.effort |
| xAI | grok-4.7、grok-4.6、grok-4.5 | 新版 Max→xhigh；4.5 Max→high |
| Google | gemini-3.8-flash、gemini-3.1-pro-preview | OpenAI 兼容接口，Max→high，前三档沿用 |
| DeepSeek | deepseek-flash、deepseek-v4-pro | low / high / high / max；Medium→High。两项按用户要求仅推理标签、无图像标签 |

Claude 用户举例 Fable 5 当前官方目录已是 Fable 5.1，采用确切名称/API ID。未加入仅用于语音、图像生成或实时音视频的模型；PromptSmith 当前发送文本。

DeepSeek Chat 使用 `thinking.type=enabled` 与 `reasoning_effort`；其 Anthropic 兼容接口使用 `thinking.type=enabled` 与 `output_config.effort`，Responses 使用 `reasoning.effort`。结构化生成、文本辅助与测试连接共用参数映射。新版默认 High，旧默认自动档迁移为 High；设置页明确保存的自动档仍遵循接口自动策略，同一模型重复选择保留已选档位。思考模式不发送无效 temperature，top_p 按官方 0.95 下限处理；最新 OpenAI/Claude 思考预设不发送不支持的采样项。其它自定义模型保留原有手动设置。

目录是可选预设，具体账号是否可调用仍由所配接口决定。「获取模型」继续读取当前服务，自定义 ID 不被目录覆盖。自定义网关保留其服务与协议；官方服务跨厂商切换同步地址与协议、清空旧密钥并要求再次确认。确认依据、DPAPI 加密、普通保存与连接测试的现有边界不变。
