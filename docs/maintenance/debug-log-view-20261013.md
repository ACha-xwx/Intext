## 初始发现

当前 RuntimeLog 的完整格式直接用单个 text 节点渲染，包含完整日期、线程和模块；`.log-line` 为 `white-space:pre`，列表 `min-width:max-content` 强制横向滚动。截图中的菜单开合和每次草稿提交又重复完整 task id。需要分离展示元信息，保留归档合同。

## 最终实现

- `LogEntry` 增加短时间、模块、正文；`text` 仍是完整原始归档。公开 Debug 快照再次脱敏，支持采集后才登记的密钥。
- Web 日志列表按时间、级别缩写、模块、正文分栏。等宽系统字体、灰色元信息、彩色级别、正文自动换行，窄窗模块省略显示且可悬停读全名。仅内部样式变化，外部工具栏和图例保持。
- 已知普通生命周期显示简短中文，例如“草稿已同步”“展开服务名称菜单”“自动保存：2项修改”。未知事件、警告、错误、多行消息及异常链保留完整正文，不改原始记录。
- 历史阅读锚点改为正文字符 Range，支持长换行、Unicode、显示裁剪及字体变化；新日志仍仅在原本位于底部时跟随。
- 复制复用实际渲染的筛选/清空/显示行数集合：完整显示记录复制原文，裁剪记录复制可见尾部。保存独立使用完整内存归档，仍只有用户点击才写盘。
