# 联网 Skill 简介评分（2026-10-14）

本项是用户暂停全项目审查后提供的第三项修改。范围是联网候选的 AI 评分与结果说明，并在三个问题完成后一起回归；不恢复旧审查或实施其整改计划。

## 目标与边界

- 已确认属于 Agent Skill 的联网候选，把独立简介 `description`、有界 `brief`、当前任务和关键工作交给一次 AI 评分请求。给出 0～1 推荐强度、具体用途和理由，按评分降序展示；低于 0.4 不推荐，不凑数。
- 不要求评分前读完正文；正文受限时可用已确认 Skill 的公开简介。简介仅是评估依据，不能宣称安装、执行或完整验证。普通网页不能因此升级为 Skill，选用时的来源和绑定校验保持。
- JSON 代码块、数字字符串和单条无效引用可恢复；真实服务、解析或全部无效评分失败明确显示原因，保留有限且有用途依据的未核验候选与重试入口。没有评分不能等同于不匹配，不增加自动重试。
- 本地默认正文复核路径、输入预算、取消与迟到隔离、SessionState 和 Tk owner 线程保持。Debug 同步生命周期与简洁摘要，原文及异常链仍脱敏、只手动保存日志。

## 根因与实现

用户引用的“AI 筛选暂不可用”是网络评分失败后的粗筛降级说明，正常路径已有 AI 审阅。当前没有当次服务异常，不能断言已定位其真实远端原因。

本地可重复的旧路径问题是：没有独立简介字段；超过八项候选先做额外元数据 AI 初筛；JSON 代码块触发解析失败；数字字符串评分或单个坏引用使整批成功评分丢失。修改后网络路径显式使用 `summary_only=True`，现有 shortlist/字符预算限制输入，最多推荐 `review_limit` 项；本地默认仍复核正文。简介上限 1,600 字符、brief 上限 2,000 字符，来源地址独立提供，完整正文不重复发送。

`skill_ai_selection.py` 保留真实模型分数、用途和理由，逐行容错并统计评分/未评分/低分排除/坏行数量。联网简介评分不受旧“仅元数据最高 0.69”上限限制，依据标注为“AI 简介评分，未阅读全文”。Web/Tk 状态显示评分完成数量，候选详情给出理由、用途和依据；失败原因经 RuntimeLog 脱敏后截短展示，完整异常保留 Debug。

增量 Standards 复核发现：`matches=[]` 曾被标记完成并显示 AI 未发现匹配。公开搜索测试复现后，简介模式零有效评分现在明确失败；真实有效低分仍为成功无匹配。追加取消探针又复现“取消后的迟到网络错误触发降级”：异常包装前重新检查作用域，取消优先退出，不生成降级结果。Controller 的 Stop 联动验证立即解锁且迟到推荐不回写。
