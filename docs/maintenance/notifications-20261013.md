# 右上角统一通知

## 目标与范围

按用户“可关闭右上弹窗警告.txt”复刻通知卡片：图标、标题、正文、关闭按钮、圆角边框与轻阴影；固定右上角并纵向排列。示例的付款/配额/版本通知只作外观参考，不成为产品功能。

工作区、设置、历史、内容编辑和独立Debug窗口共用消息呈现，迁移报错/警告/操作反馈；保留输入草稿、重试、流程内容与显式确认，详细异常仍进入完整脱敏内存日志。复用公开Controller、生产DOM与隔离WebView2测试边界；不读个人设置、不发模型请求。

## 反馈环与诊断

原生状态写入未投影通知、设置错误仍在底栏是两个已复现缺口，公开Controller和生产DOM测试各先红后绿；Debug同步恢复/复制错误隔离同样先红后绿。不是把所有日志变通知：INFO/DEBUG日志继续只在Debug。任务提问、结果、核对/删除确认及静态设置说明保留原用途。

所有业务状态由Tk-owner trace捕获，按来源替换卡片；过滤每键草稿提示和派生“最终结果/目录状态”标记，关闭后快照不重放。启动目录所有供应商通过显式反馈钩子报告，活动服务切换不重复播报。原生dialog期间通知移入当前dialog并使用top-layer浮层，关闭dialog后仍能读/关闭保留消息。

## 最新动画与计时

- 每张底部3px条使用CSS scaleX、左锚点、5秒linear，右端向左匀速缩短。每张只有一个timeout，替换/手动关闭清旧timer；移入或移出modal根据首显时间恢复进度，不重启五秒。自动关闭与手动关闭共用安全焦点转移。
- 收回140ms并在150ms移除空位，剩余通知使用240ms transform动画上移。读取当前视觉位置以支持连续关闭；不重建通知、倒计时条或独立timer，没有逐帧JS和日志。
- 横向收回溢出用overflow-x:hidden限制；上移时auto高度收缩导致临时纵向溢出，改稳定透明视口高度。真实超出窗口时仍纵向可滚动，空白区域pointer-events:none穿透到页面。减少动态效果时禁卡片/补位/底条动画，5秒期限不变。

完整[通知文案清单](notification-messages-20261013.md)由[源盘点脚本](notification_inventory.py)生成，F34前端、B220业务、D68动态来源、G17模型失败帮助、E78校验/桥接、S5排除项。保留Tk兼容/旧入口与动态错误模板明确标注，不能把清单条数当作主界面按钮数或有限的服务端异常集合。
