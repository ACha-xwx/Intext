# 需求内联、单次整理与主动停止

日期：2026-10-12。范围来自父对话本轮反馈；接续此前未提交的 WebView2 工作，不用 HEAD 作为修复前基线。使用 planning-with-files、diagnosing-bugs、tdd、planning-and-task-breakdown 与 code-review；固定快照见 [before](../../verification/requirements_stop_20261012/before/)，独立差异与指纹见 [验收目录](../../verification/requirements_stop_20261012/)。

## 根因与两个不同的长耗时案例

原三段连续思考来自 `invoke_m1()` 的自动纠正循环。模型把待确认候选 p1 当作已采用需求的替换目标，第一次和第二次都触发“修改候选没有引用已有需求”，程序又各自发出新请求。两次耗时为 214244ms、166757ms，分别产生 37284、28511 个思考 token。编辑空格只是触发路径，不能靠枚举空格、删字或同义词解决调用机制。

最新 402.745 秒是另一种情况：同一个请求以 deepseek-flash / max 运行，completion_tokens=65536，reasoning_tokens=65536，finish_reason=length，正文为空。不是三次自动重试，也不是输入未被识别；单次模型将全部输出预算用于思考。设置中的 120 秒是网络阻塞等待参数，流不断传来时不等于总请求截止。这里只记录成本和原因，不复制个人任务原文、请求输入或密钥。

## 实现

- M1 一次用户操作仅调用一次模型。Schema/语义检查、本地规范化和安全恢复仍保留；移除隐式修正/semantic bridge 的追加模型请求。无法采用时保留回答、候选及证据，下一步由用户明确触发。精简提示的既有改动保留，不自动调整任何阶段的思考强度或输出预算。
- 明确候选编辑通过 SessionState 本地写入用户原文来源、版本和操作关系，不自动确认。编辑前分析已当前时延续分析依据，允许核对后直接进入 M2；新补充尚未评估时不允许借编辑绕过整理。下游旧成果仍失效。
- 需求核对完整表格和操作放入对话，当前访谈充分后显示；删除顶部需求按钮与“是这个意思”。确认前的来源、解释、问题、冲突和精确预览校验保留。顶部方案核对和任务摘要保留。
- “继续整理回答”放在输入框上方右侧；Web 和 Tk 回退保留原动作和忙态保护。思考外层默认收起，用户打开或关闭后同一实例的分片/终态刷新不改变选择。
- 忙态发送按钮变为 Stop，绕过普通命令锁和未完成的草稿 flush。每次操作使用独立停止标识；会话/版本检查仍保留。取消时退役作用域、完成请求的取消状态、解除忙态、隔离迟到事件并保留已有成果。Skill 搜索来源恢复先前已完成状态或持久化 cancelled，不留 running。
- 已取得响应体后，Stop 用 socket.shutdown 唤醒阻塞读，再关闭响应。Web 和 Tk 都停止思考积压动画，当前视图保留已经显示的文字；恢复已取消记录时静态显示已保存的全文，不重新播放。完整原始思考仍保存在会话 trace。
- 思考预算耗尽而无正文时，界面显示具体原因、已用 token 和可执行的下一步；不会无提示卡住或盲目自动重试。Debug 同步覆盖一次请求、成本、取消、来源恢复及动画停止等生命周期，没有逐帧刷屏，没有自动保存运行日志。

## 验证与审查

回归使用公开 workflow/SessionState、实际 localhost HTTP、真实 Chromium DOM/桌面桥接与 Tk 操作边界。保留单次请求、阻塞读取消、需求内联、键盘选择、默认收起、按钮位置及积压取消的 red → green 原始记录。旧截断测试迁移到当前逐题回答状态，继续检查完整来源、答案、证据、保存恢复及用户主动紧凑重试；不恢复已删的旧树形 UI。

最终结果与完整界限见 [验收](../../verification/requirements_stop_20261012/results.md)。两轴只读复审分别为 Standards 0、Spec 0；审查中发现的停止标识复用、编辑后多余重新分析、搜索 running 残留及取消后动画继续播放都已修复并补回归。

独立 WebView2 验收使用临时存储、合成快照，浅深共 28 项通过。首次脚本存在 Bridge.snapshot 签名不匹配，已修正并重验，最终错误及错误诊断事件为空。一次截断组网络准备阶段超出 5 秒 pump 期限，同节点单独复验通过；早期失败保留，不隐去。

## 边界

UI 停止和迟到结果隔离立即生效；DNS、连接及 `urlopen` 尚未返回响应头时不能保证即时关闭传输，不能保证远端计费停止。程序可以避免重复请求并解释/中止长请求，不能保证服务端在保留 max 强度时一定及时产出正文。本轮没有新收费模型调用、个人设置/历史写入、EXE 构建或 Git 提交。历史失败不等于本轮全套测试均已执行。
