# 已选 Skill 按钮与重复操作 — 2026-10-09

用户要求选用后禁用按钮并显示已选状态，取消后恢复；本轮同时授权此前 BUG 批次的统一回归。

## 原因与实现

对话表格只按精确来源快照禁用按钮，没有更新标签；详情页刷新按“存在候选”启用按钮，不管当前行是否已经选用。后端跳过重复绑定后仍写入 Skill 状态，使版本递增并让交付失效。

两处共用选择状态：单项已选显示“已选中该 Skill”，全部已选的多行显示“所选 Skill 均已选中”，按钮禁用；混合多选只选用未选项，取消后恢复。无选中行、忙状态或过期候选不可选用。

重复业务绑定以 Skill/关键工作/使用模式识别，其他来源或新版候选也不可重复添加；原绑定快照继续单独展示和取消，详情说明如何替换来源。同一 Skill 用于不同工作仍可独立选用。投影字段不写入 SessionState，用户确认、来源与版本保护继续生效。

重复调用选用函数完全不写业务状态，已生成提示及其版本保持不变，并记录 DEBUG。实际添加/取消的 INFO 和表格呈现/筛选的 DEBUG 保留。
