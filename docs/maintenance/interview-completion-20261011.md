# 前期访谈收尾与方案面板

本批源码调整与[跳过事项修复](skipped-delivery-20261011.md)共同收尾，最新验收统一见[记录](../../verification/skipped_delivery_20261011/results.md)。

信息充分时直接结束访谈，五轮是自动上限，界面不显示轮数；上限后的每一批仍需要用户选择继续。M1 首轮 v0.24、增量 v0.17，M2 v0.5；加载器、运行资源与打包声明同步，保留旧资源用于兼容。

PromptSmith 生成交给下游 AI 的提示词，不要求用户把源码、素材或参考文件先交给本程序。真正影响方向的问题在前期核对，普通实施细节交由下游取得材料后判断；M2 新未知不再自动变成新一轮问题或阻断 Skill/最终交付。明确跳过的事项遵循最新排除语义，其他真实未知仍保留。

问题输入框 Enter 提交，Shift+Enter 换行；每题保留草稿，整批最后统一整理。长问题按实际布局宽度换行，不裁去后半段。空白、忙态和旧快照仍受保护。

右上角“核对方案”打开共享动画面板，显示完整方案、状态、关键工作核对、编辑、确认和 Skill 入口；主对话不再重复放方案块，删除孤立“步骤”标签。输入框下方快捷键提示与底部状态文字删除，内部状态及 Debug 记录保留。

测试共享窗口 fixture 增加捕获信息弹框，避免离线自动化等待人工点击；错误仍会记录并使相关断言失败。未完成/被终止的测试执行不计通过。
