## 分类与生效

自动 max_tokens 保留现有行为：普通接口 8192，验证的 DeepSeek flash/v4-pro 官方入口 65536。auto 温度保留 Chat 的 0，Responses/Messages 不发送。自动推理只在验证的 DeepSeek 入口用 low；自定义值由用户选择，实际可接受范围仍取决于服务商/模型。Messages 不同时指定 temperature/top_p。连接测试保持独立短请求，结构化输出预算不用于改变测试连接的独立输出额度。

模型参数编辑立即使确认失效；保存设置不等于确认。确认按钮只保存模型类偏好、公开连接和 DPAPI 加密凭据，不提交其他分类尚未保存的编辑，不调用模型。每次启动自动恢复密钥，但仍需明确确认。

非模型设置保存后用于后续操作，已启动搜索持有根目录/参数/客户端快照。型号/连接/模型参数变化仍触发现有过期结果检查。思考深度、分类、当前语气、当前搜索地址仍保留原流程局部控件，已有会话事实不由全局偏好改写。

## 配置位置与优先级

`%LOCALAPPDATA%/PromptSmith/settings.json` 存公开连接信息、全部偏好及 Windows 当前用户 DPAPI 加密的 API Key。旧 `diagnostics.json` 开关兼容迁移，新文件优先且独立更新不提交模型草稿。GitHub token 仍仅来自环境变量；API Key 不以明文写入设置或会话。临时验证通过 diagnostics_root / evidence_root 隔离，不写生产偏好。详见 [凭据保护](settings_security_20261009.md)。

连接/搜索已有环境变量保留启动优先级；会话保存的搜索 URL 和思考深度优先于新会话默认。设置保存时搜索索引 URL 明确更新当前会话的输入值；其他业务内容保持。

错误输入不能部分写入；保存用临时文件与原子替换，失败保留旧配置、编辑值和可重试提示，并在 Debug 记录异常。损坏设置逐字段默认回退，文件整体不可读时使用默认，不阻断启动。

实现入口：`preferences.py`、`settings_ui.py`；UI 调用继续在 `guided_flow.py` / `ui.py`。验证汇总见 [分类设置验证](../../verification/settings_20261009/results.md)。
