# 设置持久化与凭据保护

日期：2026-10-09。适用于当前源码，EXE 尚未重建。验证见 [设置加密验证](../../verification/settings_encryption_20261009/results.md)。

## 保存与恢复

全部设置以 UTF-8 保存在 `%LOCALAPPDATA%/PromptSmith/settings.json`，格式版本 2。`preferences` 包含 31 项偏好，`connection` 只包含服务、协议、地址和模型；`credentials.api_key` 包含版本、加密方案和 Base64 编码的 DPAPI 密文。Base64 仅用于表示已经加密的字节，不承担加密功能。启动自动读取普通设置并解密 API Key。2026-10-10 起，另存 `model_confirmation` 版本及公开模型配置/规范化参数/密文记录指纹；用户明确确认过且依据匹配时自动恢复确认，无历史依据首次确认一次后记住。指纹用于避免配置与确认脱节，不是对整个设置文件的签名，也不包含明文密钥或其散列。

“保存设置”保存全部当前设置和加密密钥，仅延续当前有效确认；“确认”只保存模型分类、连接、加密密钥和确认依据，写入成功后确认当前配置；“测试连接”只调用探测，不保存或确认。模型或密钥编辑使运行时确认失效，保存该草稿也移除旧确认依据。密钥输入修改会显示未保存状态，清空后点击保存即移除密文与确认。仅退出程序不会保存尚未保存的编辑。

Debug 开关单独更新保存文件，保留原来的连接和密文；不会保存其它分类或模型草稿，也不会写运行日志。新设置没有开关时读取旧 `diagnostics.json` 并尝试迁移，保留旧文件作为兼容数据；之后以新设置为准。

## 加密边界

`credentials.py` 通过标准库 ctypes 调用 `CryptProtectData` / `CryptUnprotectData`；不设置机器级保护标志，使用当前 Windows 用户保护。Windows 管理密钥，应用不存加密密码。服务名称、协议与接口地址的规范化字符串摘要作为附加熵绑定凭据；模型 ID 不参与绑定，同服务可切换模型。切换服务/地址继续清除输入密钥，启动环境变量改变连接身份时不复用已保存密钥。

密文篡改或身份不符不能解密；不允许明文、仅 Base64 或硬编码密码回退。不支持 DPAPI 的系统可保存无密钥设置，但带密钥保存会明确失败。原生输入/输出缓冲在调用结束后清零，输出通过 LocalFree 释放；Python/Tk 和实际 API 请求仍需在运行时持有明文，不能承诺所有内存副本都能可靠擦除。

DPAPI 保护静态凭据，不能隔离已登录同一 Windows 用户下的恶意进程或具有足够系统权限的攻击者。密文的可恢复性依赖 Windows 用户配置及系统密钥；迁移到其它用户/电脑时应准备重新输入，不能把文件复制当作通用密钥备份。

## 故障与诊断

先校验普通设置，再加密密钥，最后写临时文件、flush/fsync、原子替换；加密或写入失败保留之前的设置文件与编辑，确认不会成功，界面提示修改/重试。临时文件只包含密文。文件大小超限不写入。解密失败不修改原文件，普通设置仍恢复，状态栏和设置页提示重新输入；保存新密钥或清空保存可修复该凭据。

日志包含恢复/迁移、密钥是否存在、失败系统错误码及完整异常栈；不记录密文或明文。启动恢复的密钥在使用前注册 RuntimeLog 脱敏。日志继续仅点击控制台“保存日志”才写盘。测试只使用临时合成密钥及隔离数据目录，不读取生产设置中的真实凭据。
