# Skill 比较表与累计搜索结果（2026-10-09）

状态更新（2026-10-10）：源码实施与离线/实际 Tk 统一回归完成，表格、混合来源、双向累计、选用/取消/重开及迟到响应检查通过。详见 [本批报告](../../verification/bug_batch_20261009/results.md)；已选按钮见 [选用状态](skill-selection-20261009.md)。未调用真实模型或重建 EXE；下方延期描述保留为实施时记录。

## 问题和原因

统一对话把每个候选展开成长卡片，难以横向比较。联网成功已经合并数据，但对话与详情随后按总推荐分只展示前 6 项，本地候选可能全部被联网项挤掉。再次本地搜索直接替换批次，确实丢失联网候选。搜索成功还会将有绑定的状态改成 candidates_ready，影响整合入口。

## 当前修改

- 对话与详情共用表格构造与只读投影，列为选用状态、名称、来源、推荐系数、任务用途和工作标题。选中单行查看完整用途、路径、限制、证据及已有 M3 分析。
- 提供全部、本地文件、联网、内置、已选筛选；默认全部，显示各来源与选用总数。两页共享筛选与显示全部状态，Ctrl / Shift 多选、批量选用/取消仍通过 SessionState。
- 简略模式在来源间分配默认推荐名额，并额外带出当前筛选内全部已选项。推荐数小于来源数时，至少为每个来源保留一项。分数仍降序、保留初筛未核验标签。
- 两种搜索均累计合并同一方案依据的候选，重搜更新相同来源、Skill、工作和用途的候选。不同来源分别保留，空结果或失败保留已有工作；有绑定时维持 selected，整合入口继续可用。
- 旧会话只存绑定或重搜后候选版本不同，表格仍显示可查看/取消的已选快照。投影字段不写入会话，保存格式不变，新建/打开复位筛选，保留旧请求隔离。
- Debug 记录来源计数、展示与合并数量、筛选改变，选用/取消记 INFO；不记录密钥或 Skill 正文，日志仍手动保存。
