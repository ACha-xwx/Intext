依据用户 `教程.txt` 复刻圆角卡片、圆形图标、步骤计数、进度条、上一步/下一步/完成及滑动动画。组件中的示例安装文案不作为产品需求。

用户后续明确：教程应实际引导操作，完成当前步骤才可下一步；最新范围为完成模型配置；第五步说明发送首个目标，但用户可直接点击完成。只有最后一步完成才标记已完成；第一页可以跳过；设置页提供重新查看。

五步真实操作：打开模型设置 → 配置模型服务 → 获取可用模型 → 选择可用模型并自动保存 → 介绍返回工作区并输入目标（可不发送直接完成）。前四步下一步依赖生产快照和保存完成状态，不使用时间推进或仅点击教程按钮算完成。已存在的有效配置/目录可直接通过相应检查，不强迫重复获取。

非模态 top-layer 卡片高亮目标控件，应用仍可操作。宽窗卡片在左下，窄窗为引导留出底部空间；正文可以滚动，控件可达。浅深主题、系统字体、减少动画生效。

设置页“界面 → 使用教程”提供“重新查看教程”。关闭不写完成状态，本次启动不强制再次打开，下次未完成启动重新引导。首次页“跳过教程”记录 skipped，后续启动不自动展示；完成最后一步并点击完成记录 completed。二者不会混淆，重看仍从第一步开始。教程不自动发送目标、测试连接或调用模型。

## 状态与诊断

settings.json 顶层 tutorial_status 保存 skipped/completed，未保存视作 not_started。状态写入与模型/会话分离，不解密或重新加密密钥，保留当前档案；后续模型/普通偏好保存保留教程状态。完成操作仅验证当前页面版本，不要求发送目标；只有点击完成才保存completed。保存失败保留原文件和状态，右上提示“教程状态未能保存，请再试一次。”，可重试；Debug 保留完整异常。

教程打开、步骤切换、关闭、跳过/完成保存、异常有日志，无逐帧输出，也不自动保存诊断日志。
