用户要求中文默认宋体，英文与数字 Times New Roman，允许在设置页切换字体；设置页继续用默认组件。

后续清晰度修复：混排缓存升级 v6，保留西文原生 hint/ClearType 与中文安全局部 hint；普通 UI 行高不再沿用数学字体的大型公式度量，统一模式的异常字体也会生成私有度量副本。源码 DPI 感知在 Tk 创建前设置，图标使用 Pillow 平滑缩放。旧首次生成成本和此前验证保留为历史证据，最新行为及验收见 [清晰度修复](ui-clarity-20261010.md)。

采用中英文分开设置、共用正文字号。中文字体影响汉字和中文标点，英文与数字字体影响英文字母、数字和常见西文标点。关闭“分别设置中英文字体”后，全部文字使用中文字体；英文选择保留，重新开启可继续用。分开更适合中英文混排，统一模式便于用户使用一套界面字体。

设置→界面提供两项可输入/选择的系统字体列表、开关和混排预览。修改为草稿，保存后生效并写入原 settings.json，启动自动恢复；恢复本类默认也恢复宋体/TNR 与分开模式。UI 设置不进入模型确认依据，不自动测试连接、不修改任务事实；现有加密和确认保存边界保留。偏好累计为 35 项（原 31 项、组件主题 1 项、字体 3 项）。

## 原生控件混排

Tk 的按钮/Entry/Treeview/Canvas 通常只能指定一个字体，Windows 的自动回退不能保证选中中文字体。`typography.py` 读取本机安装的两种字体，用 FontTools 组合应用内的字符映射和字形：中文保留中文字体的字形，西文字母和数字使用西文字体的字形，统一到同一坐标单位。使用 Windows FR_PRIVATE 加载临时字体族，族名控制在 LOGFONT 的 31 字符范围内。

缓存位置为 `%LOCALAPPDATA%/PromptSmith/font_cache/`，按源文件身份/大小/修改时间与实现版本区分。首次准备一组字体仍需要时间，窗口先用原生字体显示，再由后台准备并在 Tk 主线程应用；后续启动直接使用缓存。字号变更复用当前准备结果，换字体/关闭使旧结果失效；不修改系统字体文件、不安装全局字体、不下载或分发系统字体。FontTools 是运行依赖，requirements/pyproject/PyInstaller 动态模块清单同步；应用分发不含本机字库。

正文、表格、按钮、菜单、输入框、模型弹层、临时编辑窗口和 Debug 共用命名字体。保存后命名字体更新，保留原字号层级/粗体及组件固定小字号；主文本字号仍可设置。模型名和四档强度继续保留原文。窗口标题和 Windows 提供的文件选择/系统消息框属于系统绘制，受系统字体设置控制。

字体缺失、不可读或不支持混排时，设置保存给出具体说明并保留原文件；已保存字体在下一次启动不可用时保留普通设置、明确提示并回退默认。TTF/TrueType TTC 支持分开设置；其它系统字体可使用统一模式。启动未能准备默认混排时使用原生宋体继续打开，日志保留完整失败原因。

## Debug 与验证

新增字体准备/缓存/私有加载/应用日志、耗时和失败完整异常链；设置保存已有日志记录变化字段。Debug 字体同步，蓝/白/黄/红级别颜色、完整记录和手动保存保持原合同。预览不写入会话；字体缓存属于 UI 资源缓存，不是运行日志。
