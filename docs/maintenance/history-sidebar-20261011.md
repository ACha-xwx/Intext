# 本地历史会话与侧栏

本轮按用户 DeepSeek 官方聊天页参考复刻历史栏的布局与交互，保留 PromptSmith 品牌和现有浅深主题。用户涂黑的标题属于隐私遮挡，不作为组件样式。

## 用户操作

- 左侧“开启新对话”自动保存当前工作后进入空白 Hero，不再弹出“请先保存”。
- 标题按“今天”“昨天”“七天内”“30天内”互斥分组：七天内为前2至6个自然日，30天内为前7至29个自然日。更早记录继续放在“更早”组。按本机时区计算；置顶独立放在最前。
- 悬停或键盘聚焦会话行可打开省略号菜单，只提供重命名、置顶/取消置顶和删除。删除有 Web 确认面板。
- 搜索图标或 Ctrl+K 打开标题搜索；不为搜索加载全部正文。Escape 关闭，Tab 在弹窗内移动，重命名可按 Enter 保存。
- 收起后为左上角品牌图标和横向展开/搜索/新建胶囊，侧栏与对话宽度有连续过渡；没有留一条空白竖轨。

## 存储和恢复

Windows 默认在 `%LOCALAPPDATA%/PromptSmith/history/` 保存：

| 文件 | 内容 |
| --- | --- |
| `index.json` | 轻量标题、置顶、时间、阶段、UUID、导入记录、文件修改标记 |
| `records/<UUID>.json` | 完整 SessionState 与该会话元数据 |

健康启动只读取索引并核对目录标记，点击才调用 `SessionState.from_dict()` 加载对应正文。不默认重开上次会话，不提前加载所有历史。索引损坏、孤儿文件或正文比索引更新时才修复关联记录；失败原文件保留并写详细 Debug 原因。

早期手动保存的默认 `sessions/` 目录和当前设置指定的会话目录首次复制导入；保留原更新时间和原文件。已导入路径记录在索引，删除历史副本后不会下次启动再导入。其它路径仍可通过“文件→打开会话”导入副本；删除副本不删外部原文件。

浏览器输入草稿以220ms防抖同步到所属会话的 `control.workspace_drafts`，包括主输入、各题回答、补答目标和滚动位置。业务记录最多每2秒检查一次变化并在单个后台线程写完整快照；每次操作前提交浏览器草稿，切换和正常退出等候检查点落盘。空白新会话不累计到历史。意外断电/强制杀进程可能丢失最后尚未写入的短暂变化。

恢复沿用 SessionState 的版本、显式确认和历史清理规则，保留需求、问答、方案、Skill绑定、最终提示、思考记录及草稿。未完成的网络请求被退役并允许重新发起，不恢复旧连接。`_install_session()` 统一文件打开和历史点击；取消旧 TaskScope，更新实例令牌，重建工作流并清忙态，迟到模型回复/流式事件/草稿不能跨会话写入。

`runtime_api_key` 不进入会话JSON；模型设置与 DPAPI 密钥仍使用原设置存储，不放进历史索引。

## 失败处理和诊断

索引和正文各自用同目录临时文件、flush/fsync和原子替换。正文写完而索引写入中断时，重启按文件标记修复。删除先将受管理正文改名为临时删除记录，再更新索引；更新失败会回滚，启动能完成/回滚中断删除。UUID格式约束阻止任意路径操作。

保存失败时保留当前内存会话、阻止切换并在侧栏显示重试。自动重试退避10秒；索引修复无法落盘仍允许读取已有记录。日志覆盖索引加载/修复、后台检查点、切换/恢复、改名/置顶/删除、旧导入、退出、迟到草稿与完整异常堆栈。继续遵守内存采集、手动“保存日志”、颜色和脱敏合同。

## 代码入口与验证

- `session_history.py`：本地目录、索引、原子记录、旧导入、日期分组。
- `history_workspace.py`：Tk所属线程协调、背景检查点、草稿保护、会话安装。
- `web_workspace.py`：窄桥接与历史元数据投影。
- `resources/ui/workspace/history.js`：侧栏、搜索、菜单、确认弹窗和草稿防抖。
- `ui.py::_install_session()`：共用恢复入口。

影响 Windows WebView2 主工作区，Tk回退继续保留文件打开/保存入口。`PromptSmith.spec` 已收集整个 workspace 目录，新增JS不需要另加资源路径。本轮源码验收见[验证记录](../../verification/history_sidebar_20261011/results.md)，没有构建新 EXE 或调用真实模型。
