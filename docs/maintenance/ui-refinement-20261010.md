# 十项界面交互调整（2026-10-10）

本次以用户的玻璃按钮、好看的下拉菜单、回复组件为视觉/动画参考，适配原生 Tk，默认字体始终直接取平台默认。

2026-10-11 用户追加：仅模型选择弹窗恢复100%原字号，搜索、名称、描述、思考强度/提示与悬浮文字一起覆盖；其余界面继续125%。局部字体比例同样用于Canvas与文字裁切，Debug同步比例/实际字号。22项相关检查及隔离浅深实际Tk显示/字体更新核对通过。此局部调整在下方早期125%验收之后完成。

- 全局字号在原基准上乘 1.25，取整数点数；标题、菜单、Debug、表格与工具提示一起放大。设置中的字号为缩放前基准。
- placeholder按Text首行dlineinfo定位，取消Label边距，pointer使用同一xterm。输入区高度按当前文字行高和工具栏计算，避免字号变化时拿到旧请求高度；提示在Text提升后同步提升，避免被遮住。切换9/12/16/18pt基准和调整窗口均复验几何区域、层级与实际截图。
- 思考正文保留16ms自适应打字机；折叠容器裁剪高度并缓动，图形chevron转动。Text自己的滚轮绑定优先返回break，独立阅读不会拖动整页。删除思考复制入口和方法。
- 每题两行圆角回答框，同排圆形发送箭头与红色“跳过”/图形交叉线。自由输入，空白/忙态禁用，Ctrl+Enter提交，草稿/逐题记录/整批最后整理仍在原业务链。
- M1提示要求不再生成options或示例答案，当前schema该字段可省略。解析补空数组兼容SessionState；旧会话options不显示。reason保留诊断，不混在问题正文。
- 需求核对与任务摘要从时间线拆出，右上顺序“一起核对需求、任务摘要、设置”。面板锚定按钮、边界受窗口/屏幕限制，点外侧/Escape/关闭收起；新建/打开/字号或主题变化销毁。仅真实窗口位置/尺寸变化才收起，Windows堆叠/曝光Configure不会误关菜单。需求编辑/移除/解释确认/替换/完整文本/明确确认保留版本保护，前期信息齐备时文字提示指向顶部核对入口。
- 删除右上保存，文件菜单保留打开/保存/另存为。对话和输入区共同居中，内容宽上限1060px。
- 输入工具栏顺序：模型、空白、整理深度、任务类型、发送。两项采用玻璃胶囊与圆角菜单，250ms hover高光/小幅缩放，菜单0.38s淡入/位移/缩放弹簧，含行图标/分隔/选中图形对勾，超高可滚动。
- 旧“需求详情”、重复任务/追问/核对表单、来源版本操作、M5偏好示例桌面入口/生成和设置项均撤除。SessionState来源/版本和旧M5数据只保留为历史兼容，不提供安装/执行Skill等新功能。
- 新组件动画、弹层、选择、输入区生命周期同步Debug，异常仍通过应用回调记录完整链；日志只在用户点击保存日志时落盘。
