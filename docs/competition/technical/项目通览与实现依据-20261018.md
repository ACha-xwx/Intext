### 2.2 前端、测试与构建口径

## 三、57 个生产 Python 文件逐项职责

这些文件构成 Python 生产包。表中“关键符号”是现有结构索引的定位摘录，不是该文件的全部接口。正常 Windows 布局入口以 Web 工作区为主，`PromptSmithApp` 仍在 Tk 所属线程持有业务对象；Tk 组件与 `_legacy_*` 方法的存在不能被解释为普通 Web 布局入口。

## 五、技术方案可追溯的实现关系

| 技术方案中的表述 | 主要实现位置 | 应保留的限定 |
| --- | --- | --- |
| 从模糊目标到确认后的需求/方案 | `guided_flow` → `workflow` → `m1/m2` → `SessionState`；Web 通过 `WorkspaceController` 派发 | AI 返回内容须经解析和用户确认；未知、跳过与已确认要求具有不同语义 |
| 配置多家模型服务 | `preferences`、`credentials`、`model_catalog`、`model_directory_refresh`、`api` | 当前五类供应商配置与三类请求协议分开；不宣称按任务自动选择最佳模型 |
| 可选 Agent Skill 发现与匹配 | 本地索引/搜索、三路联网发现、`skill_recommendation`、`skill_ai_selection`、`skill_browser` | 普通网页不自动作为 Skill；分数是推荐强度；正文/节选/简介证据要区分；不安装执行发现项 |
| 向另一个 AI 交付任务提示 | `delivery_workflow`、`m3/m4`、`finalization`、`exporter` | 交付来源引用与任务用途；下游是否能读取/执行取决于其环境，不等于意织已执行任务 |
| 本地恢复与操作保护 | `session`、`storage`、`session_history`、`history_workspace`、`task_scope` | 恢复仍需有效性校验；迟到响应不能覆盖新会话；已发出的服务端请求有取消边界 |
| 可解释运行过程与故障 | `streaming`、`runtime_log`、`web_debug`、`runlog` | 只显示服务端公开字段；运行日志保存在内存并由用户手动导出，模型证据另有存储合同 |

上述表述说明代码中的组织方式和约束，不给出未经测量的效果百分比。市场背景及相关产品事实另见[公开资料核查](../../maintenance/technical-proposal-20261018-market.md)，与本产品实现证据分别引用。
