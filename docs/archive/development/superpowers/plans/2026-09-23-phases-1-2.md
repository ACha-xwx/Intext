# PromptSmith Phases 1-2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a runnable Windows Tkinter application that saves versioned sessions and uses the existing M1 v0.2 contract to propose, review, edit, and confirm requirements through one configurable model API.

**Architecture:** `src/promptsmith` contains a UI-independent session model, JSON storage, one explicit Chat Completions API adapter, M1 request/validation/application services, and a thin Tkinter UI. Model output is always an untrusted candidate; the session model alone owns versions, confirmation, budget, stale-response rejection, and persistence. Existing prompt and Schema files remain source assets and are bundled read-only.

**Tech Stack:** Python 3.11+, standard-library Tkinter/ttk and urllib, `jsonschema` for Draft 2020-12 validation, `pytest` for tests, PyInstaller directory mode.
