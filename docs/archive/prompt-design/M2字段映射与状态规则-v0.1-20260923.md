# M2 字段映射与状态规则 v0.1

日期：2026-09-23。当前接入提示：`M2_system_v0.1.txt`；契约：`m2.v0.1`。

## 字段流转

| M2 输入 | 来源 | 空值语义 | 维护方 | 输出／持久化去向 |
|---|---|---|---|---|
| `request_id`、`task_id` | 程序会话与本次调用 | 不允许为空 | 程序 | 仅用于请求对应与证据，不由模型建立方案身份 |
| `source_requirements_version`、`confirmed_requirements_version` | 当前 Session | 必须相等 | 程序 | 保存为方案来源版本；不一致时入口拒绝或迟到拒收 |
| `task.text` | 当前已确认任务说明 | 不允许为空 | 用户经 M1 修改，程序保存 | 进入 `source_snapshot`，模型不能覆盖 M1 原文 |
| `category` | 用户类别或 M1 类别建议、类别配置 | 未选时使用 `general` | 程序 | 绑定请求；类别变化使在途结果失效 |
| `requirements` | 当前正式需求 | 至少一项 | 用户确认，程序版本化 | `requirement_coverage`、步骤、交付物、标准和关键工作只能引用这些 ID |
| `unresolved_items` | 当前 `can_defer` gaps | 可为空 | M1／用户状态，程序保守保存 | `plan.unresolved_items` 必须逐项承接，M2 不得自动解决 |
| `relevant_materials` | 被需求或未知实际引用的来源 | 可为空 | 程序筛选 | 只作资料，不取得产品指令权限 |
| `plan_context` | 当前方案 ID／版本 | 首次生成时 ID 为 null、版本为 0 | 程序 | 用于迟到响应保护；不信任模型回显 |
| `plan.goal` | 模型方案草稿 | 不允许为空 | 模型建议，用户可编辑 | `Session.plan.content.goal` |
| `requirement_coverage` | 模型逐项映射 | 必须精确覆盖全部需求一次 | 模型提出，程序校验 | 方案内容；不得引用输入外需求 |
| `steps`、`deliverables`、`completion_criteria` | 模型方案草稿 | 各至少一项 | 模型提出，用户编辑，程序维护 ID／引用 | 方案内容与结构化 UI |
| `unresolved_items` | 输入未知的方案承接 | 输入为空时可为空 | 模型说明影响，程序校验源 gap | 方案内容，不改变 M1 gap |
| `suggestions` | 独立系统建议 | 可为空 | 模型提出 | 仅展示；新增范围、成本或权限必须明确待确认 |
| `key_work` | 方案中的 1–3 项关键工作 | 不允许为空 | 模型提出，用户复核 | 保存复核状态；未复核不能确认方案 |

## 程序权限与版本

- 模型只返回局部步骤、交付物、标准、建议和关键工作 ID。`plan_id`、`plan_version`、状态、确认版本和时间戳全部由程序创建。
- 首次合法结果成为 `draft`、`plan_version=1`。目标、步骤或顺序修改递增方案版本，清除方案确认；普通方案编辑不改变需求版本。
- 新生成会把上一份方案完整放入 `plan_archive`，标记 `archived_reason=regenerated`，再创建新的 `plan_id`。
- 实际任务、类别或需求变化使当前方案保留为 `stale`，清除方案确认。仅导航到需求页不改变版本。
- 确认方案要求：来源需求仍是当前已确认版本、结构和引用有效、没有待复核关键工作。可延后未知允许保留。

## 入口拒绝、失败与过期拒收

- 调用前拒绝：需求未确认、确认版本过期、候选未处理、开放冲突、需求待复核、方向性未知、悬空引用或依赖。
- Schema 合法不等于业务成功。`status=error` 记录为模型内容错误，不应用空方案，不覆盖旧草稿。
- 网络、解析、Schema、语义、结构化错误与迟到响应均保留已有方案和用户修改；应用前完成全部校验，一次性写入。
- 返回时核对请求、任务、任务文本、类别、需求／确认版本、发起时方案 ID／版本和连接配置快照。重复、失效或迟到响应不接收。
- 当前实现对非法模型输出不自动无限重试；由用户修正输入或显式重试。证据保留原始响应和校验错误。

## 主要错误类型

| 类型 | 含义 | 用户路径 |
|---|---|---|
| `insufficient_input` | 输入仍不足以形成完整方案 | 返回需求页补充或重新确认 |
| `unsupported_input` | 输入超出当前 M2 契约可表达范围 | 修改任务范围或保留为未支持项 |
| `safety_or_permission` | 缺少必要权限或存在不能越权处理的事项 | 明确权限后重试 |
| `contract_issue` | 输入内部结构使模型无法按契约返回 | 程序／开发侧检查映射 |

人工样例位于 `examples_m2/`，其 `evidence_type` 为 `manual_fixture`，不代表真实模型输出。
