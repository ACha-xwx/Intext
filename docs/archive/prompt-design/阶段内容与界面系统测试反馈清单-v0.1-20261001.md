# PromptSmith 阶段内容与界面系统测试反馈清单

**版本**：v0.1
**日期**：2026-10-01
**用途**：记录真实使用中的内容质量、流程引导、按钮布局和界面冗余问题，为下一轮修改方案提供证据。
**当前状态**：待用户实际填写；填写完成后再制定修改方案。

## 一、填写方式

每次测试尽量使用同一个可用的模型配置，并记录当前软件版本、测试时间和任务原话。不要一边测试一边修改程序；先完成一组记录，再统一分析。

每个问题只记录三件事：

1. **实际发生了什么**：用户点击了什么、软件显示了什么、模型返回了什么；
2. **为什么影响使用**：用户不知道下一步、需要重复操作、输出不符合目标、布局干扰阅读等；
3. **严重程度**：
   - **阻断**：无法继续，或无法得到可用结果；
   - **明显问题**：可以绕过去，但会影响演示或普通用户理解；
   - **轻微问题**：措辞、间距、按钮位置等细节，不影响完成任务。

请尽量保留截图或复制实际文字。没有实际出现的问题不要凭猜测填写。
