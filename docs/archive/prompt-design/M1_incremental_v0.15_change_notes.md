# M1 incremental v0.15

这版补充增量回答的桥接规则：用户只补充领域或线索时也要正常继续访谈；“你自己查一下”不能让流程报错或逼用户填写全称；模型需要保留缺口并提出候选或具体问题。

这是提示设计与离线契约检查版本，尚未单独完成真实模型对比测试。

本轮增补：增量回答也按快速、标准、深入的覆盖目标继续追问；模型认为信息还不够时不因旧计数器结束。若模型的判断和下一步动作矛盾，程序保留当前缺口并提供下一条可回答的问题。以上是离线检查结果，尚未完成真实 API 的内容质量对比。
