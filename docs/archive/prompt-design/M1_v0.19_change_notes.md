# M1 v0.19 改动说明

这次修改针对“模型把信息不足当成错误，导致用户卡住”的问题。

- 保留 `M1_system_v0.18.txt` 与 `M1_incremental_v0.11.txt`，新版本在它们之后追加语义桥接规则。
- 模型返回可解析但语义不完整的 `input_error` 时，程序会再次发送专门的语义桥接提示，让模型重新判断回答并生成正常追问。
- 只有 JSON、字段契约、网络或 API 等技术问题继续走失败路径；语义缺口不会直接弹错误。
- `quality_policy=model_judgment_first` 明确告诉模型：旧的轮数和问题数量字段不决定需求是否充分。
- 连续桥接仍有内部防死循环上限；达到上限时保留已有缺口并生成可继续问题，用户不会被要求重新输入任务。

当前自动化验证属于离线合成测试，尚未证明真实模型在所有自然语言场景下都会稳定输出理想判断。
