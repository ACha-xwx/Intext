## 一、项目是什么

PromptSmith（需求引导式提示构建助手）。Python 3.11 + Tkinter 桌面应用，PyInstaller 单文件 EXE 发行。用于第八届全球校园人工智能算法精英大赛赛题二。

**核心设计**：模型的输出永远只是候选，状态的更改权在程序手里。模型返回的内容要经过 Schema 校验、语义校验和来源校验，进入待审候选区，必须由人点"接受"才落到正式状态。这条把"模型幻觉直接污染交付物"在架构层面掐掉了，是本作品最值钱的设计。

**流程**：M1（需求提取与动态追问）→ M2（完整初始方案 + 关键工作）→ M3（Skill 候选分析）→ M4（增量整合）→ M5（局部 A/B 示例与反馈）→ 末端交付（无 Skill 确定性组装、受控语气、短文本试运行、复制／导出／保存重开）。

**入口**：
- 启动 `run_promptsmith.py` → `src/promptsmith/main.py` → `ui.py`
- 领域模块 `m1.py` / `m2.py` / `m3.py` / `m4.py` / `m5.py` / `skill_catalog.py` / `trial.py` / `finalization.py` / `delivery_workflow.py` / `workflow.py`
- 状态 `session.py` / `storage.py`；输出 `exporter.py`；模型调用唯一出口 `api.py`；证据写入 `runlog.py`；资源定位 `paths.py`
