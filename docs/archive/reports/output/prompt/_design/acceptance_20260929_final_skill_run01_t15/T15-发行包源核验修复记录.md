# T15 发行包源核验修复记录

记录日期：2026-09-29

## 问题与修复

`PromptSmith.spec` 只把 Skill 目录摘要和 NOTICE 放入单文件发行包，没有把 `source_path` 指向的原始 Skill 文件一起分发。UI 在刷新已选绑定时若始终执行 `verify_sources=True`，发行包会把所有合法绑定误判为 `source_unavailable` 并使最终结果过期。

`src/promptsmith/ui.py::_refresh_selected_catalog()` 现在按运行环境选择核验方式：源码环境继续通过 `SkillCatalog.verify_sources()` 检查本地来源文件是否被修改或删除；PyInstaller 运行环境识别 `sys._MEIPASS` 后只按目录记录哈希和绑定快照核验，沿用目录说明中的 `catalog_recorded` 语义。目录记录本身变化、删除或目录不可用仍会使绑定过期。绑定快照不会被替换。
