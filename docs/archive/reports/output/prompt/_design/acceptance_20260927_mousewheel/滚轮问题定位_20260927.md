# 滚轮问题定位

日期：2026-09-27。范围：用户报告主页面鼠标滚轮无反应的原因定位及修复提示设计。未修改产品代码。

## 结论

**需求页外层 Canvas 缺少滚轮事件接线，问题已在当前源码的 Tk 事件路径复现。** 现有滚动条和 Canvas 移动能力已建立，但不能据此判定鼠标滚轮可用。

## 原因与旧检查的覆盖缺口

`src/promptsmith/ui.py:233–257` 的 `_scrollable_page` 只连接滚动条、`yscrollcommand`、`scrollregion` 和 `<Configure>`，没有添加滚轮路由。检索 `src`、`tests`、`scripts` 中的 `MouseWheel`、`Button-4`、`Button-5`、`bind_all`、`unbind_all`、`bindtags` 未发现相关实现。

`tests/test_experience_acceptance_fix.py:375–406` 在模拟缩放条件下直接调用 `canvas.yview_moveto(1.0)` 后验证详情可达；`scripts/verify_ui_layout.py` 同样直接移动 Canvas。此类检查验证布局和可达性，未验证滚轮事件到滚动动作的连接。历史报告和测试结果保留，不追改为没有进行过的鼠标验收。
